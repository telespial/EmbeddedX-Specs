# EmbeddedX Interoperability

Recommended conceptual direction:

* Machine Readable Datasheet (MRD) defines hardware-visible capability
* Machine Readable Connectivity (MRC) defines actual board connectivity
* Model Definition Package (MDP) defines model interface and behavior
* Embedded Intelligence Layer (EIL) defines runtime intelligence integration
* AI Integrated Coding System (AICS) defines controlled coding, validation, and recovery
* Embedded Intelligence Package (EIP) defines deployment structure

Projects should also respect the shared library vs project workspace distinction established by the EmbeddedX project framework.
