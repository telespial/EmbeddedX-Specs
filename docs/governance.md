# EmbeddedX Governance

This repository should remain stable, architectural, and system-level.

Detailed technical rules for Machine Readable Datasheet (MRD), Machine Readable Connectivity (MRC), Model Definition Package (MDP), Embedded Intelligence Layer (EIL), AI Integrated Coding System (AICS), and Embedded Intelligence Package (EIP) should stay in those repositories unless a change affects the platform as a whole.
