# EmbeddedX Roadmap

## Platform-Focused Development Path

Proposed by: Richard Haberkern  
Contact: rmhaberkern@gmail.com  

Free for evaluation. Commercial use requires permission. See license.md for more information.

* * *

## 1. Phase 1 — Platform Foundation

* define umbrella repository structure
* define platform philosophy
* define architectural model
* define repository relationships
* define interoperability guidance
* define templates for sibling repositories

* * *

## 2. Phase 2 — Specification Alignment

* align MRD terminology and structure
* align MDF terminology and structure
* align EIL runtime positioning
* align AICS generation and validation terminology

* * *

## 3. Phase 3 — Examples and Reference Material

* create a small number of cross-specification examples
* add walkthroughs
* add diagrams
* add platform-level compatibility notes

* * *

## 4. Phase 4 — Tooling and Conformance

* define validator expectations
* define optional conformance materials
* define reference converters and validators
* define example implementation pathways

* * *

## 5. Phase 5 — Public Review and Iteration

* publish ecosystem repositories
* gather engineer feedback
* refine terminology and interoperability rules
* preserve a strong separation between open specifications and proprietary implementations where needed
