## AICS

AI Coding Specification. Defines how AI systems generate, modify, validate, and present code changes.

## Advisory Mode

A runtime mode where AI outputs inform firmware or operators without directly taking autonomous control.

## EIL

Embedded Intelligence Layer. Defines runtime integration of embedded intelligence into firmware.

## EmbeddedX

The umbrella platform specification coordinating related repositories and platform-level rules.

## MDF

Model Definition Format. Defines structure and semantics for embedded AI model packages.

## MRD

Machine Readable Datasheet. Defines firmware-relevant hardware meaning in machine-readable form.

## Traceability

The ability to link an artifact back to its source specification, input, or engineering meaning.

## Validation

The process of checking whether generated or integrated artifacts satisfy constraints such as compile success, lint checks, interface compliance, or test outcomes.
